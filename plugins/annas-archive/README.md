# annas-archive — книги и статьи одной фразой

Скилл-библиотекарь для Claude Code. Вы называете книгу — Claude ищет её в Архиве Анны, выбирает лучший файл, качает членским API и отчитывается об остатке квоты.

## Как пользоваться

Отдельная команда не нужна — скилл поднимается сам на фразах вроде:

- «скачай The Mom Test в epub»
- «найди книгу Обречены побеждать»
- «скачай эти книги: …» (список — одним батчем)
- «скачай статью по DOI 10.1038/nature12373»

Явный вызов: `/annas-archive <запрос>`.

## Настройка ключа

Скачивание идёт через членский API быстрых загрузок — нужен активный аккаунт Архива Анны и его API-ключ (страница аккаунта на сайте). Поиск работает и без ключа.

Способ 1 (рекомендуется) — `~/.claude/settings.json`:

```json
{
  "env": {
    "ANNAS_ARCHIVE_KEY": "<ваш-ключ>"
  }
}
```

Файла ещё нет — это его содержимое целиком. Файл уже есть — добавьте в него только пару `env`.

Способ 2 — профиль шелла: `export ANNAS_ARCHIVE_KEY="<ваш-ключ>"` в `~/.zshenv` (zsh) или `~/.bashrc` (bash).

После правки — перезапустите Claude Code.

## Smoke-тест

```
скачай The Mom Test в epub
```

Ожидаемо: файл `~/Books/AnnasArchive/Rob Fitzpatrick — The Mom Test (2013).epub`, в отчёте — формат, размер, год и остаток быстрых загрузок.

## Что внутри

| Файл | Роль |
|---|---|
| `skills/annas-archive/SKILL.md` | инструкция: политика выбора, фоллбэки, обработка ошибок |
| `skills/annas-archive/scripts/aa_search.py` | поиск (парсинг HTML `/search`), режимы DOI и `--meta` |
| `skills/annas-archive/scripts/aa_download.py` | скачивание через `/dyn/api/fast_download.json`, проверка файла |

Оба скрипта — stdlib + `curl`, без зависимостей. HTTP идёт через `curl`, потому что WAF отдаёт 403 на запросы из `urllib`.

## Политика выбора файла

1. Совпадение названия и автора.
2. Флаг быстрой загрузки (🚀) — обязателен, иначе членский API файл не отдаст.
3. Формат: EPUB → PDF → MOBI/AZW3 → FB2/DJVU.
4. Язык: английский по умолчанию (или тот, что вы попросили).
5. При равенстве: больше зеркал-источников → новее год → размер не микроскопический.

## Troubleshooting

| Симптом | Причина и что делать |
|---|---|
| `ERROR: ANNAS_ARCHIVE_KEY not set` | Ключ не виден сессии — добавьте по инструкции выше и перезапустите Claude Code |
| `API error: Invalid secret key` | Ключ истёк или скопирован с обрезкой — проверьте членство и перевыпустите |
| `API error` про quota | Дневная квота быстрых загрузок исчерпана — Claude сохранит md5 недокачанного |
| `all mirrors failed` | Зеркала недоступны из вашей сети — задайте своё: `ANNAS_ARCHIVE_MIRROR=https://<домен>`, туда же, в блок `env` (или профиль шелла), и перезапустите Claude Code |
| `ERROR: scripts not found` | Плагин установлен некорректно — переустановите: `/plugin install annas-archive@becyborg-library` |
| `downloaded file suspiciously small` | Партнёрский сервер отдал заглушку — Claude возьмёт следующего кандидата |

## Ограничения

- Повторное скачивание того же md5 **тратит квоту** (проверено на практике вопреки FAQ про 18-часовой дедуп) — скилл проверяет папку перед загрузкой.
- Поиск парсит HTML сайта: смена вёрстки может потребовать правки `aa_search.py`.
