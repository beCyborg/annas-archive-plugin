# annas-archive-plugin

Плагин для Claude Code, который превращает фразу «скачай The Mom Test в epub» в файл на диске.

Claude сам ищет книгу в [Архиве Анны](https://annas-archive.org), сам выбирает из десятков дублей лучший файл (EPUB → английский → больше зеркал → новее), качает его членским API быстрых загрузок и говорит, сколько загрузок осталось на сегодня. Умеет списки («скачай эти двенадцать книг») и научные статьи по DOI.

## Что он делает вместо вас

Обычный ручной путь — открыть сайт, вбить название, глазами перебрать двадцать записей с одинаковыми обложками, угадать, где EPUB не битый, нажать скачивание, повторить для каждой книги из списка. Плагин снимает всё это:

- **Выбор файла.** Кандидаты ранжируются по формату, языку, числу библиотек-зеркал, году и размеру; записи без флага быстрой загрузки отбрасываются сразу — их членский API не отдаёт.
- **Фоллбэки.** Нет EPUB → PDF → MOBI/AZW3 → FB2/DJVU. Нет ничего на английском → Claude показывает варианты на других языках и спрашивает.
- **Батч.** Список книг качается в цикле с паузами, в конце — таблица «книга / формат / год / файл» и остаток квоты. Кончилась квота — стоп со списком недокачанного.
- **DOI.** Строка вида `10.1038/nature12373` уходит в `/scidb` точным попаданием, при промахе — в индекс журналов.
- **Проверка файла.** После скачивания сверяется magic-байт (EPUB → `PK`, PDF → `%PDF`): заглушку партнёрского сервера видно сразу.

## Prerequisites

- Claude Code (любая платформа), `python3` и `curl` в PATH — обычно уже есть.
- **Членство в Архиве Анны и API-ключ** — без него работает поиск, но не скачивание. Ключ — на странице аккаунта после оформления членства.

## Установка

Терминал не нужен: обе команды набираются прямо в строке ввода Claude Code, одна за другой.

```
/plugin marketplace add https://github.com/beCyborg/annas-archive-plugin.git
/plugin install annas-archive@becyborg-library
```

`becyborg-library` — имя маркетплейса, который добавляет первая команда; во второй подставляется именно оно. Ссылка дана полным HTTPS-URL намеренно: короткая форма `owner/repo` клонируется по SSH, а SSH-ключа на GitHub у вас может не быть.

Предпочитаете терминал — те же два шага командами CLI (в десктопном приложении терминал открывается через **Views → Terminal** или `Ctrl` + `` ` ``):

```bash
claude plugin marketplace add https://github.com/beCyborg/annas-archive-plugin.git
claude plugin install annas-archive@becyborg-library
```

## Ключ

Положите ключ в блок `env` файла `~/.claude/settings.json` — он действует во всех сессиях Claude Code и во всех запускаемых из них процессах:

```json
{
  "env": {
    "ANNAS_ARCHIVE_KEY": "<ваш-ключ>"
  }
}
```

Файла ещё нет — это его содержимое целиком. Файл уже есть — добавьте в него только пару `env` (а если блок `env` там уже был — одну строку с ключом внутрь него).

Альтернатива — профиль шелла (`export ANNAS_ARCHIVE_KEY="..."` в `~/.zshenv` или `~/.bashrc`). В обоих случаях после правки перезапустите Claude Code: переменные читаются при старте сессии.

## Проверка

Скажите Claude: «скачай The Mom Test в epub». Он найдёт книгу, скачает её в `~/Books/AnnasArchive/` и отчитается остатком квоты. Файл лежит на месте — плагин работает.

Без ключа Claude остановится на первом шаге и покажет инструкцию по настройке — это ожидаемое поведение, а не поломка.

## Куда кладутся файлы

По умолчанию — `~/Books/AnnasArchive/`, имя вида `Автор — Название (Год).epub`. Нужна другая папка — скажите об этом в запросе.

## Безопасность

- Ключа в репозитории нет и быть не может: скрипты читают его из переменной окружения и вычищают из текста ошибок.
- Плагин ходит только на зеркала Архива Анны (`.gl` → `.pk` → `.gd`, с ротацией) и на выданный API адрес загрузки.
- Соблюдение авторского права в вашей юрисдикции — на вашей стороне.

## Версии

`version` в манифестах не задан — версией служит commit SHA, то есть обновление доезжает с каждым новым коммитом, без ручных бампов.

Забирается оно командой `/plugin update annas-archive@becyborg-library`. Само по себе не приедет: авто-обновление включено по умолчанию только у официальных маркетплейсов Anthropic — для стороннего его надо один раз включить в `/plugin` → **Marketplaces** → `becyborg-library` → **Enable auto-update**.

Имена маркетплейса (`becyborg-library`) и плагина (`annas-archive`) зафиксированы с первого релиза: переименование ломает существующие установки.
